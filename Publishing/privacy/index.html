What data we collect

None. Tilevault 2048 does not collect, transmit, or share any personal data. There are no accounts, no sign-in, no analytics, no advertising identifiers, and no crash reporting. Nothing you do in the game is sent anywhere.

The application requests a single Android permission, VIBRATE, used only to produce the short vibration when tiles merge. It can be switched off in Settings. The application does not request the network, location, camera, microphone, contacts, or storage permissions.

What is stored on your device

The game writes one save file to its own private application storage. No other application can read it, and it never leaves the device:

  • your best score for each board size and game mode;
  • your daily challenge best score and streak;
  • the game currently in progress, so closing the app does not lose it;
  • your settings: sound, vibration, chosen theme and unlocked themes.

Uninstalling the application deletes this file and everything in it. You can also erase it at any time from Settings → Reset progress. There is no backup copy anywhere, so a reset or an uninstall is permanent.

Network

The application has no network access. It does not hold the INTERNET permission, so it is unable to open a network connection even in principle. The game is fully playable offline, because offline is the only way it runs.

Advertising and analytics

There are no advertisements and no analytics or tracking software of any kind. No third-party SDK is embedded in the application, so no third party receives data about you.

Purchases

The application is free and contains no in-app purchases and no subscriptions.

Children

The application is not directed at children under 13. Because it collects no data at all, no personal information can be gathered from users of any age.

Changes to this policy

If a future version of the application changes what it does — for example by adding advertisements or any network feature — this policy will be updated before that version is published, and the effective date above will change.
